# 📊 E-commerce Analytics Project (SQL)

## 🔍 Overview
This project simulates an e-commerce business scenario and demonstrates how SQL can be used to design databases, query data, and extract actionable business insights. It reflects my passion for data analytics and my ability to bridge technical skills with business logic.

## 🧱 Database Design
The project includes three core tables:
- `customers`: Stores customer details and signup information.
- `orders`: Tracks order status and dates.
- `order_items`: Contains product-level details for each order.

All tables are normalized and connected via foreign keys to ensure relational integrity.

## 🧠 Key SQL Concepts Used
- Joins (INNER, LEFT)
- Aggregations (SUM, COUNT, AVG)
- Window functions
- Conditional logic with CASE
- Common Table Expressions (CTEs)
- Grouping and filtering

## 📈 Business Insights Extracted
- Total revenue and category-wise breakdown
- Customer Lifetime Value (CLV)
- Active vs inactive customers
- High-value and repeat customers
- Order status distribution
- Average Order Value (AOV)
- First purchase date per customer
- Category performance flags

## 💡 Why This Project Matters
This project showcases how raw transactional data can be transformed into meaningful metrics that drive business decisions. It’s a hands-on demonstration of my love for data analytics and my readiness to solve real-world problems using SQL.

## 🚀 How to Run
1. Clone the repository.
2. Use any SQL environment (e.g., MySQL, PostgreSQL, SQLite).
3. Run the `schema.sql` file to create and populate the database.
4. Execute queries from `analysis.sql` to explore insights.
